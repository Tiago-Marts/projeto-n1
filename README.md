# SISTEMA DE LOJA DE JOGOS DIGITAIS
Esse projeto, construído para componente da nota da N1 da disciplina de Programação Estruturada, é um menu interativo no qual o usuário pode comprar jogos, ver sua coleção e alterar seus dados.

## Objetivos
O projeto utilizou funções, switchs, loops e estruturas de dados para poder executar suas tarefas.
